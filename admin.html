A chave fica só neste navegador e é usada apenas para salvar no GitHub.
Como criar a chave (só uma vez)
  1. Entre no GitHub com a conta atendimentokairosdigital-bit e abra Criar token (fine-grained).
  2. Token name: Painel AbbaJu · Expiration: escolha um prazo (ex.: 1 ano).
  3. Repository access: “Only select repositories” → abbaju-catalog.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Clique em Generate token, copie a chave e cole aqui.
